# projeto-programa-o-1

A ideia é ser um site onde músicos possam criar uma conta e salvar todas as músicas que já aprenderam a tocar. Em cada música, o usuário poderá colocar informações como o nome, o artista e a cifra com os acordes, deixando tudo organizado em um só lugar.
O objetivo é facilitar na hora de tocar em um ensaio, apresentação ou até mesmo em casa, sem precisar procurar cifras em vários sites ou anotações. Assim, cada usuário terá seu próprio repertório salvo e poderá acessar suas músicas de forma rápida e prática.
O que vai poder ser feito pelo usuario: cadastro, cadastrar musicas, editar musicas, colocar os acordes da musica, se tem capotraste ou nao, qual o tom da musica etc, vai poder criar pastas de musicas para separar de forma organizada, alem de tambem poder cadastrar musicas proprias.
